# Тестовое задание
Два микросервиса, API Gateway, JWT аутентификация, Clean Architecture, CQRS, UnitTests

## Для запуска
0. Правим в конфигах проектов строки подключения к БД (Jwt.SecretKey не трогаем, умышленно влил в VCS для упрощения)
1. Запускаем Api/DbMigrator.WebApi для наката миграций БД.
2. Запускаем Infrastructure/Currency.BackgroundWorker для наполнения БД данными.
3. Разворачиваем Redis с помощью docker-compose.yml (Postgres забыл добавить, т.к. свой инстанс локально всегда крутится)
4. Запускаем
   * UserService.WebApi
   * FinanceService.WebApi
   * ApiGateway

## Не всё успел:
* Накат миграций БД через API - для меня новое, поэтому сделал только базовое решение.
* Юнит-тестами покрыл только хендлеры, до некоторых сервисов и репозиториев не добрался.
* Не требовалось, но стоило бы добавить Dokerfiles и инструкции запуска сервисов в docker-compose.yml
